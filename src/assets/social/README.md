# Social-card font

Liberation Mono Regular 2.1.5 is used only while generating static sharing images.
It is one of the website's existing system-font fallbacks. It is not imported by
page CSS, preloaded, or served as a browser font.

Source: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5
Original archive: https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz
