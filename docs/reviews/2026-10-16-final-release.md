## Measurements and checks

- Before vs footnote preview: HTML gzip 5,723 → 5,910 bytes. HTML-linked JS **188,008 → 188,008 bytes gzip**. CSS **4,542 → 4,602 bytes gzip**. These are computed gzip sizes, not a full browser transfer waterfall. Vercel serves Brotli where supported; lazy vector data is additional.
- Handwriting WOFF2: **4,684 bytes**, self-hosted, preloaded only on the homepage, swap fallback. Offline shaping/raster checks confirm R/O counters remain open in ligatures and individual glyphs.
- Observed Chromium portrait cycle: starts about **2.0 s** after ready; **16.7 ms median**, **18.1 ms p95** frame interval, **0 CLS**, **0 animation long tasks**. This is an unthrottled lab observation, not field CWV or low-end-phone proof.
- Main text contrast: ink 14.21:1; muted/footer 5.24:1; blue links 6.67:1; small headings 7.15:1 on `#faf9f6`. Axe reports contrast checks as incomplete for textured/pseudo-element backgrounds; ratios and screenshots supplement those checks, not a WCAG certification.
- Keyboard original-text toggle exposes all 82 Japanese paragraphs in Genjō Kōan and has visible focus. Reduced-motion fixture stays static and switches image/vector on demand. The text-zoom fixture doubles rendered text; it is not a native browser zoom or screen-reader session.
- `npm run check`, `npm run format:check`, `npm run build`, `npm run check:output`, and offline handwriting validation pass. Archived 161 originals and translation prose remain intact.
- Vercel response: CSP, HSTS (two years), nosniff, DENY, strict-origin referrer policy, restrictive Permissions-Policy. Homepage cache HIT; static assets immutable for one year. No third-party script tags in emitted pages.
- RSS, sitemap, robots, llms, manifest, apple icon and favicon return 200. Missing URL, `/privacy`, `/blog`, `/archive/` return intended 404. Four translations appear in feed/sitemap. HTML content is crawlable without JS; headings remain normal text.
- API-rendered levels: **English [Native], Español [8], 日本語 [3], 한국어 [1], Français [0.1]**. Links use validated API URLs. No guessing, rounding or browser fetch.
- Footnote is in the shared footer; on reader pages its numbered backlink returns to Languages on the homepage.
