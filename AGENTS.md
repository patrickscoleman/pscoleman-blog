Patrick's existing biography. Use the notebook rules and dotted guides, restrained
blue accents, monospace interface type, and readable serif translation text.

- Work on a codex/ branch. Open a draft PR.

  deploy updates to production without an extra approval round; report the result.

- Run npm run check, npm run format:check, and npm run build.
- Review at 320px, a usual phone width, both sides of the layout breakpoint, and desktop.
  Check keyboard focus, 200% text zoom, original-text controls, and intended 404s.
- Keep the archive immutable and outside routes, public assets, lint, and formatting.
- Preserve translation prose, poem line breaks, source text, and attribution.
